# Doc Klasoru Indeksi

Bu klasor projedeki merkezi dokuman deposudur.

## Icerik

- Klasik proje notlari: `doc/*.md`
- Calisma loglari ve metin dosyalari: `doc/*.txt`
- Omoda5 kitap icerigi: `doc/KITAP_OMODA5_ARŞIV/`

## Kural

- Yeni dokumanlar varsayilan olarak bu klasore kaydedilir.
- Ayni konuda mevcut belge varsa yeni dosya acmadan once mevcut belge guncellenir.
